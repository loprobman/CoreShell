# help — show help for built-in commands

Display a list of all built-in commands, or detailed help for a specific command.

## Usage

```
help  [-h] [[command]]
```

## Options

| Option | Description |
|--------|-------------|
| `[command]` | command to show help for |
| `-h, --help` | show this help and exit |

## Examples

```sh
help             # list all built-in commands
help ls          # show detailed help for ls
help cp          # show detailed help for cp
```
